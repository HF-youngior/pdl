# 数据库加载问题解决方案

## 🚨 问题描述

在加载增强示例数据时出现错误：
```
ERROR 1062 (23000) at line 7: Duplicate entry 'task-022' for key 'tasks.PRIMARY'
Error: Failed to load enhanced sample data
```

## 🔍 问题原因

数据库中已经存在相同ID的记录，导致主键冲突。

## ✅ 解决方案

### 方案1：使用安全的数据加载脚本（推荐）

```bash
cd backend
load_safe_enhanced_data.bat
```

**特点**：
- 使用 `INSERT IGNORE` 避免重复键错误
- 只添加不存在的记录
- 安全可靠，不会破坏现有数据

### 方案2：完全清理并重新加载

```bash
cd backend
clean_and_reload_data.bat
```

**特点**：
- 清理所有增强数据
- 重新加载基础数据
- 重新加载增强数据
- 确保数据一致性

### 方案3：手动清理特定记录

如果只想清理特定的重复记录：

```sql
-- 连接到数据库
mysql -u root -p enterprise_management

-- 删除可能重复的任务
DELETE FROM tasks WHERE id IN ('task-022', 'task-023', 'task-024', 'task-025', 'task-026', 'task-027', 'task-028', 'task-029', 'task-030', 'task-031', 'task-032', 'task-033', 'task-034', 'task-035');

-- 删除可能重复的日志
DELETE FROM personal_logs WHERE id IN ('log-005', 'log-006', 'log-007', 'log-008', 'log-009', 'log-010', 'log-011', 'log-012', 'log-013', 'log-014');

-- 删除可能重复的系统日志
DELETE FROM system_logs WHERE id IN ('sys-log-005', 'sys-log-006', 'sys-log-007', 'sys-log-008', 'sys-log-009', 'sys-log-010', 'sys-log-011');
```

## 📊 数据验证

加载完成后，您可以通过以下方式验证数据：

### 1. 检查任务数量
```sql
SELECT COUNT(*) as task_count FROM tasks;
```

### 2. 检查日志数量
```sql
SELECT COUNT(*) as log_count FROM personal_logs;
SELECT COUNT(*) as sys_log_count FROM system_logs;
```

### 3. 检查任务进度
```sql
SELECT id, title, progress_percentage, status FROM tasks WHERE progress_percentage > 0;
```

## ⚠️ 注意事项

1. **备份数据**：在清理数据前，建议先备份重要数据
2. **端口检查**：确保使用正确的端口（8080）
3. **权限检查**：确保数据库用户有足够的权限
4. **连接检查**：确保数据库服务正在运行

## 🔧 故障排除

### 如果仍然出现错误：

1. **检查数据库连接**：
   ```bash
   mysql -u root -p -e "SHOW DATABASES;"
   ```

2. **检查表结构**：
   ```sql
   DESCRIBE tasks;
   DESCRIBE personal_logs;
   DESCRIBE system_logs;
   ```

3. **检查现有数据**：
   ```sql
   SELECT id FROM tasks WHERE id LIKE 'task-0%' LIMIT 10;
   ```

4. **清理特定记录**：
   ```sql
   DELETE FROM tasks WHERE id = 'task-022';
   ```
