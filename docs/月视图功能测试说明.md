# 月视图功能测试说明

## 功能概述

月视图功能允许用户在日历中查看指定月份的所有任务和日志，并支持：
- 月份导航（上一月/下一月）
- 日期数据指示器（显示哪些日期有数据）
- 点击日期查看详细信息
- 在详情浮窗中编辑/删除任务和日志

## 后端API实现

### 1. 月视图API
**端点**: `GET /api/calendar/month-view`

**参数**:
- `year`: 年份（如 2024）
- `month`: 月份（1-12）

**返回格式**:
```json
{
  "year": 2024,
  "month": 2,
  "days": [
    {
      "date": "2024-02-01",
      "tasks": [],
      "logs": [],
      "hasData": false
    },
    {
      "date": "2024-02-15",
      "tasks": [
        {
          "id": "task-001",
          "title": "Develop HR Department Annual Plan",
          "description": "",
          "status": "pending",
          "priority": "p1",
          "start_time": null,
          "end_time": null,
          "deadline": "2024-02-15T18:00:00.000Z",
          "is_all_day": 0,
          "assignee_name": "Wang HR Director",
          "color": "#3b82f6"
        }
      ],
      "logs": [],
      "hasData": true
    }
  ],
  "summary": {
    "totalTasks": 1,
    "totalLogs": 0,
    "daysWithData": 1
  }
}
```

**实现文件**: `backend/server_enterprise.js` (第1534-1640行)

**主要逻辑**:
1. 获取指定月份的所有日期（1-最后一天）
2. 查询该月份用户的所有任务（通过start_time, end_time或deadline判断）
3. 查询该月份用户的所有日志（通过created_at判断）
4. 将任务和日志按日期分组
5. 返回每日数据和月度统计

### 2. 日详情API
**端点**: `GET /api/calendar/day-detail`

**参数**:
- `date`: 日期（格式：YYYY-MM-DD，如 2024-02-15）

**返回格式**:
```json
{
  "date": "2024-02-15",
  "tasks": [
    {
      "id": "task-001",
      "title": "Develop HR Department Annual Plan",
      "description": "",
      "status": "pending",
      "priority": "p1",
      "start_time": null,
      "end_time": null,
      "deadline": "2024-02-15T18:00:00.000Z",
      "is_all_day": 0,
      "assignee_name": "Wang HR Director",
      "color": "#3b82f6"
    }
  ],
  "logs": []
}
```

**实现文件**: `backend/server_enterprise.js` (第1642-1755行)

**主要逻辑**:
1. 解析日期参数
2. 查询该日期的所有任务
3. 查询该日期的所有日志
4. 返回合并后的数据

### 3. 任务更新API
**端点**: `PUT /api/tasks/:id`

**请求体**:
```json
{
  "priority": "p1",
  "status": "completed"
}
```

**实现文件**: `backend/server_enterprise.js` (第1173-1233行)

### 4. 任务删除API
**端点**: `DELETE /api/tasks/:id`

**实现文件**: `backend/server_enterprise.js` (第1234-1284行)

### 5. 日志更新API
**端点**: `PUT /api/logs/:id`

**请求体**:
```json
{
  "title": "更新后的标题",
  "content": "更新后的内容"
}
```

**实现文件**: `backend/server_enterprise.js` (第1449-1503行)

### 6. 日志删除API
**端点**: `DELETE /api/logs/:id`

**实现文件**: `backend/server_enterprise.js` (第1504-1559行)

## 前端实现

### 1. API Service
**文件**: `lib/services/api_service.dart`

添加了以下方法：
- `getMonthView(int year, int month)`: 获取月视图数据
- `getDayDetail(String date)`: 获取日详情数据

### 2. Calendar Service
**文件**: `lib/services/calendar_service.dart`

实现了完整的数据模型和服务方法：
- `MonthViewData`: 月视图数据模型
- `DayData`: 单日数据模型
- `CalendarTask`: 日历任务模型
- `CalendarLog`: 日历日志模型
- `DayDetailData`: 日详情数据模型
- `MonthSummary`: 月度统计模型

服务方法：
- `getMonthView()`: 获取月视图数据
- `getDayDetail()`: 获取日详情数据
- `updateTask()`: 更新任务
- `deleteTask()`: 删除任务
- `updateLog()`: 更新日志
- `deleteLog()`: 删除日志

### 3. Calendar Widget
**文件**: `lib/widgets/calendar_widget.dart`

实现了完整的月视图UI组件：

**主要功能**:
1. **月视图显示** (`_buildMonthView()`)
   - 日历网格布局（7列×N行）
   - 星期标题行
   - 日期单元格
   - 数据指示器（任务用蓝色条，日志用绿色条）
   - 今日高亮显示

2. **数据加载** (`_loadMonthViewData()`)
   - 加载状态显示
   - 错误处理和重试
   - 自动刷新

3. **日期详情浮窗** (`_showDayDetail()`)
   - 精美的圆角对话框设计
   - 标题栏显示日期和统计信息
   - 任务列表（带状态和优先级标签）
   - 日志列表（带分类和象限标签）
   - 编辑/删除按钮
   - 添加任务按钮

4. **任务编辑** (`_showEditTaskDialog()`)
   - 修改优先级（P0-P3）
   - 修改完成状态（待处理/进行中/已完成/已取消）

5. **日志编辑** (`_showEditLogDialog()`)
   - 修改标题
   - 修改内容

6. **删除确认**
   - 任务删除确认对话框
   - 日志删除确认对话框

```sql
WHERE assignee_id = ? 
  AND (
    (DATE(start_time) = ?)
    OR (DATE(end_time) = ?)
    OR (DATE(deadline) = ?)
    OR (start_time IS NULL AND DATE(deadline) = ?)
  )
```

### 日志日期匹配逻辑

WHERE user_id = ?
