# DeepSeek API 集成使用指南

## 概述

本指南介绍如何在AI地图模块中使用DeepSeek API进行性格分析和预测推荐功能。

## 功能特性

- **智能性格分析**：基于用户日志内容进行MBTI性格分析
- **职业建议**：提供个性化的职业发展建议
- **工作环境推荐**：分析适合的工作环境和团队角色
- **本地备用方案**：API不可用时自动使用本地算法
- **历史记录**：保存所有分析结果供后续查看

## 配置步骤

### 1. 获取DeepSeek API Key

1. 访问 [DeepSeek官网](https://platform.deepseek.com/)
2. 注册账号并登录
3. 在控制台中创建API Key
4. 复制API Key备用

### 2. 配置环境变量

在 `backend/.env` 文件中添加以下配置：

```env
# DeepSeek API配置
DEEPSEEK_API_KEY=your-deepseek-api-key-here
DEEPSEEK_API_URL=https://api.deepseek.com/v1/chat/completions
```

### 3. 启动服务

```bash
cd backend
npm start
```

## 使用方法

### 前端使用

1. 打开Flutter应用
2. 进入AI地图模块
3. 切换到"性格分析"标签页
4. 点击"AI性格分析（DeepSeek）"按钮
5. 等待分析完成，查看结果

### API接口

#### 性格分析接口

**POST** `/ai/personality-analysis`

**请求参数：**
```json
{
  "logText": "用户日志内容",
  "mbtiType": "ENFP",
  "useDeepSeek": true
}
```

**响应示例：**
```json
{
  "id": "123",
  "userId": "user-001",
  "analysisDate": "2025-01-27T10:00:00Z",
  "personalityTraits": {
    "外向性": 0.8,
    "宜人性": 0.6,
    "尽责性": 0.9,
    "神经质": 0.3,
    "开放性": 0.7
  },
  "mbtiType": "ENFP",
  "workSuggestions": {
    "适合职业": ["产品经理", "市场营销", "创意总监"],
    "工作环境": "开放、创新、团队合作",
    "发展建议": "发挥创造力，加强执行力",
    "沟通风格": "热情、富有感染力"
  },
  "personalityChart": {
    "traits": { ... },
    "dimensions": { ... }
  }
}
```

#### 词云分析接口

**POST** `/ai/save-wordcloud`

**GET** `/ai/wordcloud-history`

#### 性格分析历史接口

**GET** `/ai/personality-history`

## 错误处理

### 常见错误及解决方案

1. **API Key无效**
   - 检查环境变量配置
   - 验证API Key是否正确

2. **网络连接失败**
   - 检查网络连接
   - 确认API服务状态

3. **JSON解析失败**
   - 系统会自动使用本地备用算法
   - 检查API响应格式

4. **API额度不足**
   - 检查DeepSeek账户余额
   - 考虑升级套餐

### 本地备用方案

当DeepSeek API不可用时，系统会自动切换到本地分析算法：

- 基于关键词匹配的简单分析
- 提供基础的性格特质评估
- 确保功能始终可用

## 成本控制

### 免费额度

- DeepSeek提供一定的免费额度
- 建议在开发阶段使用免费额度测试

### 成本优化

1. **缓存机制**：相同内容不重复分析
2. **本地备用**：API不可用时使用本地算法
3. **批量处理**：合并多个请求减少API调用

## 安全注意事项

1. **API Key保护**：
   - 不要将API Key提交到版本控制
   - 定期轮换API Key
   - 使用环境变量存储

2. **数据隐私**：
   - 用户日志数据会发送到DeepSeek API
   - 确保符合数据保护法规
   - 考虑敏感信息过滤
