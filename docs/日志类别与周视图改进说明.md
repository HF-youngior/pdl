# 日志类别与周视图改进说明

## 更新时间

## 功能概述
本次更新为10-11月份的日志添加了类别分类，并改进了周视图，使其能够用不同颜色的矩形框显示不同类别的任务和日志。

```sql
-- 更新示例
```

## 📅 三、周视图改进

### 3.1 功能增强

#### 3.1.1 数据加载
- 添加了 `_weekViewData` 变量存储周视图数据
- 新增 `_loadWeekViewData()` 方法，并行加载一周7天的数据
- 切换到周视图或导航到新的一周时自动重新加载数据

```dart
Map<String, DayDetailData> _weekViewData = {}; // 周视图数据

Future<void> _loadWeekViewData() async {
  setState(() {
    _isLoading = true;
    _error = null;
  });

  try {
    final weekStart = _getWeekStart(_currentDate);
    final weekDays = List.generate(7, (index) => weekStart.add(Duration(days: index)));
    
    // 并行加载一周的数据
    final futures = weekDays.map((day) => CalendarService.getDayDetail(day));
    final results = await Future.wait(futures);
    
    // 存储到map中
    final Map<String, DayDetailData> dataMap = {};
    for (int i = 0; i < weekDays.length; i++) {
      final dateKey = '${weekDays[i].year}-${weekDays[i].month.toString().padLeft(2, '0')}-${weekDays[i].day.toString().padLeft(2, '0')}';
      dataMap[dateKey] = results[i];
    }
    
    setState(() {
      _weekViewData = dataMap;
      _isLoading = false;
    });
  } catch (e) {
    setState(() {
      _error = e.toString();
      _isLoading = false;
    });
  }
}
```

#### 3.1.2 显示任务和日志
- 周视图同时显示任务和日志
- 每个任务和日志用彩色矩形框显示

- 日志根据类别使用不同颜色（工作/会议/学习/个人）

#### 3.1.3 交互功能

- 浮窗中显示该日期的所有任务和日志
- 每个日志显示中文类别（工作/会议/学习/个人）
- 支持编辑、删除任务和日志
- 支持添加新任务
- 长按日期可以快速添加新任务

### 4.2 视图切换逻辑

```dart
void _changeView(CalendarView view) {
  setState(() {
    _currentView = view;
  });
  
  if (view == CalendarView.month) {
    _loadMonthViewData();
  } else if (view == CalendarView.week) {
    _loadWeekViewData();
  }
}

void _navigateDate(int days) {
  setState(() {
    switch (_currentView) {
      case CalendarView.month:
        _currentDate = DateTime(_currentDate.year, _currentDate.month + days);
        break;
      case CalendarView.week:
        _currentDate = _currentDate.add(Duration(days: days * 7));
        break;
      case CalendarView.day:
        _currentDate = _currentDate.add(Duration(days: days));
        break;
    }
  });
  
  if (_currentView == CalendarView.month) {
    _loadMonthViewData(showToast: true);
  } else if (_currentView == CalendarView.week) {
    _loadWeekViewData();
  } else {
    widget.onDateSelected(_currentDate);
  }
}
```

## 📝 六、使用说明

### 6.1 查看周视图

1. 打开应用，进入"任务视图"界面
2. 点击右上角的"周"按钮切换到周视图
3. 周视图显示一周7天，每天显示该日期的任务和日志标题
4. 不同类别的日志用不同颜色的矩形框显示：
   - 蓝色 = 工作
   - 紫色 = 会议
   - 绿色 = 学习
   - 橙色 = 个人

### 6.2 查看详情

1. 点击任意任务或日志标题
2. 弹出该日期的详情浮窗
3. 浮窗中显示：
   - 该日期的所有任务（带状态和优先级）
   - 该日期的所有日志（带类别和象限）
   - 每条记录都有编辑和删除按钮

### 6.3 编辑和管理

- **编辑**：在详情浮窗中点击任务或日志旁边的编辑按钮
- **删除**：在详情浮窗中点击任务或日志旁边的删除按钮
- **添加任务**：点击浮窗底部的"添加任务"按钮，或长按周视图中的日期
- **切换周份**：使用顶部的左右箭头按钮

### 6.4 类别识别

在周视图中，通过颜色快速识别日志类别：
- **蓝色矩形**：工作类日志（如日常工作、项目推进、业务处理）
- **紫色矩形**：会议类日志（如启动会、周会、宣讲会、培训）
- **绿色矩形**：学习类日志（如学习新知识、研究调研、思考总结）
- **橙色矩形**：个人类日志（如个人事务、工作总结、数据汇总）
