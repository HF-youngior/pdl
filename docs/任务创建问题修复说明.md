# 任务创建问题修复说明

## 🔧 修复的问题

### 1. 网页端创建任务失败问题

**错误信息**：
```
TypeError: Bind parameters must not contain undefined. To pass SQL NULL specify JS null
```

**原因分析**：
- 后端创建任务时，某些字段值为 `undefined`
- MySQL不接受 `undefined` 值，必须使用 `null` 或有效值
- 部门ID字段可能为undefined

**修复方案**：
1. 后端代码改进（`backend/server_enterprise.js`）：
   - 添加字段验证，确保必填字段不为空
   - 自动获取被分配人的部门ID（如果前端未提供）
   - 将所有 `undefined` 值转换为 `null`
   - 为可选字段提供默认值

2. 前端代码改进（`web_admin/app.js`）：
   - 修复部门字段显示逻辑
   - 确保事件监听器正确绑定
   - 处理用户对象可能缺少字段的情况

3. HTML模板修正（`web_admin/index.html`）：
   - 修正优先级选项为正确的格式（p0-p3）
   - 添加正确的默认值

### 2. Android端Kotlin版本问题

**问题**：
- Kotlin版本1.9.22过旧
- 10个编译错误

**修复**：
- 更新Kotlin版本从1.9.22到1.9.24
- 这个版本更新可以解决大部分兼容性问题

```javascript
if (!title || !assignee_id) {
  return res.status(400).json({ error: '任务标题和被分配人是必填项' });

// 2. 自动获取部门ID
const [assigneeRows] = await db.execute(
  'SELECT name, department_id FROM users WHERE id = ?',
  [assignee_id]
);
const actual_department_id = department_id || assigneeRows[0].department_id;

// 3. 处理undefined值
await db.execute(
  `INSERT INTO tasks (...) VALUES (...)`,
  [
    taskId, 
    title, 
    description || null,  // undefined转换为null
    parent_task_id || null,
    // ... 其他字段
  ]
);
```

### 前端改进

```javascript
// 修复部门显示
document.addEventListener('change', function(e) {
    if (e.target.id === 'taskAssignee') {
        const selectedUser = users.find(user => user.id === e.target.value);
        if (selectedUser) {
            const deptField = document.getElementById('taskDepartment');
            if (deptField) {
                deptField.value = selectedUser.department_name || selectedUser.department || '';

        }
```
