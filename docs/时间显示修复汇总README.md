## 🔧 技术要点

### 修复1：跨多天任务显示

#### 核心逻辑（月视图）
```javascript
// 遍历任务的每一天
while (currentDate <= endDate) {
  const dateKey = '2025-10-15';  // 示例
  calendar[dateKey].tasks.push(task);  // 在每一天都添加
  currentDate.setDate(currentDate.getDate() + 1);
}
```

#### 核心逻辑（日视图）
```sql
WHERE (
  DATE(start_time) = '2025-10-15'           -- 开始于该日
  OR DATE(end_time) = '2025-10-15'          -- 结束于该日
  OR (DATE(start_time) <= '2025-10-15'      -- 跨越该日
      AND DATE(end_time) >= '2025-10-15')
)
```
