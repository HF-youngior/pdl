# 跨多天任务显示修复总结

## 修复日期
2025年10月30日

## 问题描述

在月视图和日视图中，跨多天的任务只在开始日期显示，不在后续日期显示，导致与周视图的甘特图数据不一致。

**具体案例：**
- 任务："秋季校园招聘行程规划"
- 时间：2025-10-02 09:00 至 2025-10-04 17:00（共3天）
- **修复前**：只在10月2日显示
- **修复后**：在10月2、3、4日都显示

## 修复内容

### 1. 后端修改

**文件：** `backend/server_enterprise.js`

#### 修改1：月视图 API (`/api/calendar/month-view`)

**位置：** 第1740-1814行

**改动：**
- 移除SQL查询中的 `DISTINCT` 关键字（避免与 ORDER BY 冲突）
- 重写任务分配逻辑，使跨多天任务在每一天都显示

```javascript
// 新逻辑
tasks.forEach(task => {
  if (task.start_time && task.end_time) {
    const currentDate = new Date(task.start_time);
    const endDate = new Date(task.end_time);
    
    // 遍历每一天
    while (currentDate <= endDate) {
      const dateKey = formatDate(currentDate);
      if (calendar[dateKey]) {
        calendar[dateKey].tasks.push(task);
      }
      currentDate.setDate(currentDate.getDate() + 1);
    }
  }
});
```

#### 修改2：测试月视图 API (`/api/month-view/:userId/:year/:month`)

**位置：** 第1857-1979行

**改动：** 与修改1相同

#### 修改3：日视图 API (`/api/calendar/day-detail`)

**位置：** 第1993-2022行

**改动：** 改进SQL查询，确保能获取跨越该日期的所有任务

```sql
WHERE t.assignee_id = ?
AND (
  (DATE(t.start_time) = ?)           -- 开始日期
  OR (DATE(t.end_time) = ?)          -- 结束日期  
  OR (DATE(t.start_time) <= ? AND DATE(t.end_time) >= ?)  -- 跨越该日期
  OR (DATE(t.deadline) = ?)          -- deadline日期
)
```

### 日期遍历逻辑

```javascript
const currentDate = new Date(taskStartDate);
currentDate.setHours(0, 0, 0, 0);  // 重置到00:00:00
const endDate = new Date(taskEndDate);
endDate.setHours(0, 0, 0, 0);

while (currentDate <= endDate) {
  // 处理当前日期
  const dateKey = formatDateToYYYYMMDD(currentDate);
  addTaskToCalendar(dateKey, task);
  
  // 移动到下一天
  currentDate.setDate(currentDate.getDate() + 1);
}
```

### SQL查询优化

**关键改进点：**
```sql
-- 新增这个条件来捕获跨越目标日期的任务
OR (DATE(t.start_time) <= ? AND DATE(t.end_time) >= ?)
```

这个条件确保了即使任务的开始和结束都不在目标日期，只要任务跨越了该日期，也能被查询到。
