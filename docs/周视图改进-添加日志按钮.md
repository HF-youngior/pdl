# 周视图改进 - 添加日志按钮功能

## 更新时间
2025-10-23

## 功能概述
本次更新在周视图的浮窗中添加了"添加日志"按钮，并确保周视图同时显示任务和日志。

---

## 📋 需求说明

### 用户需求
1. **在浮窗中添加两个按钮**：
   - 添加任务按钮（蓝色，图标：add_task）
   - 添加日志按钮（绿色，图标：edit_note）

2. **周视图同时显示任务和日志**：
   - 任务显示为彩色矩形框
   - 日志根据类别显示不同颜色的矩形框

3. **按钮功能**：
   - 点击"添加任务"跳转到任务编辑界面
   - 点击"添加日志"跳转到日志添加界面

## 🎯 使用说明

### 1. 从周视图添加日志

1. 打开应用，进入"任务视图"
2. 切换到"周"视图
3. 点击任意日期的任务或日志标题
4. 在弹出的浮窗底部点击"添加日志"按钮
5. 进入日志添加界面
6. 填写日志信息（标题和内容必填）
7. 选择类别、天气等信息
8. 点击右上角"保存"按钮

### 2. 从周视图添加任务

1. 在周视图中点击任意日期
2. 在浮窗底部点击"添加任务"按钮
3. 进入任务编辑界面
4. 填写任务信息
5. 保存任务

### 3. 快速添加

- **长按日期**：可以快速添加任务（跳过浮窗，直接进入任务编辑界面）
- **点击日期**：先显示浮窗，再选择添加任务或日志

## 🐛 注意事项

### 1. User 参数传递
- ViewScreen 需要 User 参数才能创建日志
- 确保 HomeScreen 正确传递 user 参数
- 日志创建时需要 user.id

### 2. 日期格式
- LogEditScreen 接收 `DateTime?` 类型的 `initialDate`
- 如果未提供，默认使用当前日期
- 保存时格式化为 ISO 8601 格式的日期字符串

### 3. 任务加载
- LogEditScreen 需要加载任务列表以支持任务关联
- 异步加载，显示加载指示器
- 失败时不影响日志创建

### 4. 数据验证
- 标题和内容为必填字段
- 保存前进行表单验证
- 失败时显示 SnackBar 提示
