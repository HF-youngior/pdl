## 🔧 故障排除

### 常见问题

1. **数据库密码仍然是加密的**
   ```bash
   # 运行强制更新脚本
   cd backend
   force_update_passwords.bat
   ```

2. **端口8080被占用**
   ```bash
   # 检查端口占用
   netstat -ano | findstr :8080
   
   # 如果被占用，可以修改server_enterprise.js中的端口号
   ```

3. **Web端无法加载用户和任务**
   - 确认后端服务已启动在端口8080
   - 检查浏览器控制台是否有错误
   - 确认API地址已更新为8080端口

### 验证步骤

1. **验证数据库密码**
   ```sql
   USE enterprise_management;
   SELECT username, password FROM users WHERE username = 'admin';
   -- 应该显示: admin | admin123 (明文)
   ```

2. **验证后端服务**
   ```bash
   curl http://localhost:8080/api/departments
   -- 应该返回部门列表JSON
   ```

3. **验证登录功能**
   ```bash
   curl -X POST http://localhost:8080/api/auth/login \
   -H "Content-Type: application/json" \
   -d '{"username":"admin","password":"admin123"}'
   -- 应该返回用户信息和token
   ```
