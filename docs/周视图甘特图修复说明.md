# 周视图甘特图修复说明

## 📅 修复日期：2025-10-30

## 🎯 问题描述

### 修复前的问题

1. **周视图显示不一致**：周视图中10/7-10/9的任务，在月视图和日视图中位置不对应
2. **缺少甘特图功能**：周视图没有跨天任务的甘特图横条显示
3. **周日不显示任务**：周视图的"星期日"列不显示任何任务或日志

### 用户期望

- 周视图以**甘特图形式**显示跨多天任务
- 10/7-10/9的任务应该横跨这三天（周二、周三、周四）
- 任务在周视图、月视图、日视图中的日期显示**完全一致**
- 周日列应该能正常显示任务和日志

## 🔧 修复方案

### 核心改动：重新实现周视图为甘特图

**文件：** `lib/widgets/calendar_widget.dart`

#### 1. 重构 `_buildWeekView()` 方法

**修复前：**
- 每一天单独显示任务列表
- 跨天任务在每一天都显示完整的任务卡片
- 无法直观看出任务的时间跨度

**修复后：**
- 收集整周所有任务并去重
- 以甘特图形式渲染跨天任务
- 任务横条准确横跨其时间范围内的所有日期

#### 2. 新增甘特图渲染方法

##### `_buildWeekGanttChart()`
构建周视图甘特图的整体布局：
- 背景：7列日期网格
- 前景：甘特图任务和日志横条

##### `_buildGanttTaskBar()`
构建单个任务的甘特图横条：
- 使用 `_extractDateFromISO()` 提取日期，避免时区转换
- 计算任务在本周的起始和结束列索引
- 只显示在本周范围内的任务

##### `_buildGanttLogBar()`
构建单个日志的甘特图横条：
- 日志只显示在创建当天
- 使用相同的日期提取逻辑

##### `_extractDateFromISO()`
从ISO字符串安全提取日期：
```dart
DateTime _extractDateFromISO(String isoString) {
  final datePart = isoString.split('T')[0];  // '2025-10-07'
  final parts = datePart.split('-');
  return DateTime(
    int.parse(parts[0]),  // year
    int.parse(parts[1]),  // month
    int.parse(parts[2]),  // day
  );
}
```

##### `_buildGanttBar()`
渲染甘特图横条的通用方法：
- 使用 `Expanded` widget 实现横跨多列
- 左侧空白：占据 `startIndex` 列之前的空间
- 甘特图条：横跨 `span` 列
- 右侧空白：占据 `endIndex` 列之后的空间

## 🎨 甘特图渲染逻辑

### 日期覆盖计算

对于任务时间 `2025-10-07T09:00:00+08:00` 到 `2025-10-09T18:00:00+08:00`：

1. **提取日期**（不含时区转换）
   - 起始日期：2025-10-07
   - 结束日期：2025-10-09

2. **遍历本周7天**
   ```dart
   for (int i = 0; i < weekDays.length; i++) {
     final day = weekDays[i];
     final dayOnly = DateTime(day.year, day.month, day.day);
     
     // 检查任务是否覆盖这一天
     if (dayOnly.isAtSameMomentAs(taskStartDate) || 
         (dayOnly.isAfter(taskStartDate) && dayOnly.isBefore(taskEndDate)) ||
         dayOnly.isAtSameMomentAs(taskEndDate)) {
       startIndex ??= i;
       endIndex = i;
     }
   }
   ```

3. **渲染横条**
   - 对于10/6-10/12这一周：
     - 周一（10/6）：不覆盖
     - 周二（10/7）：覆盖 ✅ startIndex = 1
     - 周三（10/8）：覆盖 ✅
     - 周四（10/9）：覆盖 ✅ endIndex = 3
     - 周五（10/10）：不覆盖
     - 周六（10/11）：不覆盖
     - 周日（10/12）：不覆盖
   - 结果：横跨3列（列1-3），显示在10/7、10/8、10/9

### 横条布局

使用 `Row` + `Expanded` 实现横跨多列：

```dart
Row(
  children: [
    // 左侧空白（占据startIndex列之前的空间）
    ...List.generate(startIndex, (_) => const Expanded(child: SizedBox())),
    
    // 甘特图条（横跨span列）
    Expanded(
      flex: span,  // span = endIndex - startIndex + 1
      child: Container(...),
    ),
    
    // 右侧空白（占据endIndex列之后的空间）
    ...List.generate(6 - endIndex, (_) => const Expanded(child: SizedBox())),
  ],
)
```

## 🔑 关键技术点

### ❌ 错误做法

```dart
// 直接使用 DateTime.parse() 会触发时区转换
final startTime = DateTime.parse('2025-10-07T09:00:00+08:00');
// 如果系统时区不是 +08:00，日期可能会偏移
```

### ✅ 正确做法

```dart
// 直接从字符串提取日期部分
final datePart = '2025-10-07T09:00:00+08:00'.split('T')[0];  // '2025-10-07'
final parts = datePart.split('-');
final date = DateTime(
  int.parse(parts[0]),
  int.parse(parts[1]),
  int.parse(parts[2]),
);
// 完全避免时区转换问题
```

### 去重逻辑

由于后端API为每一天返回跨天任务，前端收集所有任务后需要去重：

```dart
final uniqueTasks = <String, CalendarTask>{};
for (final task in allTasks) {
  uniqueTasks[task.id] = task;  // 使用任务ID作为key自动去重
}
final taskList = uniqueTasks.values.toList();
```

## ⚠️ 注意事项

### 关于周日显示

周视图按**周一到周日**显示一周：

- **10月20-26日这一周**：
  - 周一（10/20）到周日（10/26）
  - 10月26日（周日）的任务会显示在这一周的最后一列
  
- **10月27-11月2日这一周**：
  - 周一（10/27）到周日（11/2）
  - 10月27-29日的任务会横跨前三天

**周日能正常显示任务**，只是要注意查看包含该周日的那一周。

### 时区一致性

所有视图（周视图、月视图、日视图）现在使用相同的日期提取逻辑：
- **前端**：`_extractDateFromISO()` 直接提取日期字符串
- **后端**：`new Date(year, month, day)` 直接创建日期对象
- **结果**：完全避免时区转换，三个视图显示完全一致
