# 周视图功能测试指南

## 测试日期
2025-10-23

## 测试前准备

### 1. 启动后端服务
```bash
cd backend
node server_enterprise.js
```
确保服务运行在 `http://localhost:8080`

### 2. 确保数据库有测试数据
- 确保数据库中有一些任务和日志数据
- 如果没有，可以通过Web管理界面或API添加一些测试数据

### 3. 启动Flutter应用
```bash
flutter run
```
或通过Android Studio运行应用

## 测试场景

### 场景1：切换到周视图
**步骤：**
1. 打开应用，登录账号
2. 进入"任务视图"界面
3. 点击右上角的"周"按钮

**预期结果：**
- 视图切换到周视图
- 显示本周7天的日期（星期一到星期日）
- 如果正在加载，显示加载指示器
- 加载完成后，显示每天的任务和日志标题

### 场景2：查看任务和日志标题
**步骤：**
1. 在周视图中观察显示的内容

**预期结果：**
- 任务标题显示为彩色矩形块（根据任务颜色）
- 日志标题显示为彩色矩形块（根据日志分类：工作=绿色，个人=橙色，学习=紫色）
- 标题文本清晰可读，使用白色字体
- 长标题自动换行，最多显示2行
- 已完成的任务显示删除线

### 场景3：点击任务/日志标题查看详情
**步骤：**
1. 在周视图中点击任意任务或日志标题

**预期结果：**
- 弹出该日期的详情浮窗
- 浮窗顶部显示日期和统计信息（X个任务 · X个日志）
- 显示该日期的所有任务（蓝色标签区域）
- 显示该日期的所有日志（绿色标签区域）
- 每个任务/日志都有编辑和删除按钮
- 底部有"添加任务"按钮

### 场景4：在详情浮窗中编辑任务
**步骤：**
1. 点击任意任务标题打开详情浮窗
2. 点击任务卡片上的"编辑"按钮（蓝色铅笔图标）
3. 在编辑对话框中修改任务标题或内容
4. 点击"保存"

**预期结果：**
- 显示编辑任务对话框
- 可以修改任务标题、内容、优先级、完成状态
- 保存成功后显示"任务更新成功"提示
- 浮窗自动刷新，显示更新后的内容
- 周视图中的任务标题也更新

### 场景5：在详情浮窗中删除任务
**步骤：**
1. 点击任意任务标题打开详情浮窗
2. 点击任务卡片上的"删除"按钮（红色垃圾桶图标）
3. 在确认对话框中点击"删除"

**预期结果：**
- 显示确认删除对话框
- 确认后任务被删除
- 显示"任务删除成功"提示
- 浮窗自动刷新，被删除的任务不再显示
- 周视图中的任务标题也消失

### 场景6：在详情浮窗中编辑日志
**步骤：**
1. 点击任意日志标题打开详情浮窗
2. 点击日志卡片上的"编辑"按钮
3. 在编辑对话框中修改日志标题或内容
4. 点击"保存"

**预期结果：**
- 显示编辑日志对话框
- 可以修改日志标题和内容
- 保存成功后显示"日志更新成功"提示
- 浮窗自动刷新，显示更新后的内容
- 周视图中的日志标题也更新

### 场景7：在详情浮窗中删除日志
**步骤：**
1. 点击任意日志标题打开详情浮窗
2. 点击日志卡片上的"删除"按钮
3. 在确认对话框中点击"删除"

**预期结果：**
- 显示确认删除对话框
- 确认后日志被删除
- 显示"日志删除成功"提示
- 浮窗自动刷新，被删除的日志不再显示
- 周视图中的日志标题也消失

### 场景8：点击日期区域查看详情
**步骤：**
1. 在周视图中点击某一天的空白区域（不是标题）

**预期结果：**
- 弹出该日期的详情浮窗
- 显示效果与点击标题相同

### 场景9：长按日期添加任务
**步骤：**
1. 在周视图中长按某一天的区域
2. 填写任务信息
3. 保存任务

**预期结果：**
- 跳转到任务编辑界面
- 任务日期自动设置为被长按的日期
- 保存后返回视图界面
- 新任务显示在周视图中

### 场景10：在详情浮窗中添加任务
**步骤：**
1. 点击任意日期打开详情浮窗
2. 点击底部的"添加任务"按钮
3. 填写任务信息
4. 保存任务

**预期结果：**
- 浮窗关闭，跳转到任务编辑界面
- 任务日期自动设置为该日期
- 保存后返回视图界面
- 新任务显示在周视图中

### 场景11：切换到下一周
**步骤：**
1. 在周视图中点击右箭头按钮

**预期结果：**
- 显示下一周的日期（日期标题更新）
- 显示加载指示器
- 加载完成后显示下一周的任务和日志

### 场景12：切换到上一周
**步骤：**
1. 在周视图中点击左箭头按钮

**预期结果：**
- 显示上一周的日期（日期标题更新）
- 显示加载指示器
- 加载完成后显示上一周的任务和日志

### 场景13：无数据的日期
**步骤：**
1. 在周视图中观察没有任务和日志的日期

**预期结果：**
- 该日期的列显示为空白
- 点击该日期弹出详情浮窗
- 浮窗中显示"该日期没有任务和日志"提示
- 仍然可以使用"添加任务"按钮

### 场景14：错误处理
**步骤：**
1. 关闭后端服务
2. 在周视图中切换周份

**预期结果：**
- 显示错误提示界面
- 显示错误信息
- 提供"重试"按钮
- 点击"重试"按钮可以重新加载

## 性能测试

### 测试1：加载速度
**步骤：**
1. 切换到周视图
2. 记录加载时间

**预期结果：**
- 加载时间应该在2秒以内（取决于网络和数据量）
- 使用了并行加载优化

### 测试2：切换流畅度
**步骤：**
1. 快速连续切换周份（点击左右箭头）

**预期结果：**
- 切换流畅，无明显卡顿
- 加载状态清晰可见

### 测试3：滚动性能
**步骤：**
1. 在有大量任务/日志的日期列中滚动

**预期结果：**
- 滚动流畅，无明显卡顿
- 标题显示正常

- 测试跨月的周（例如月末到下月初）
- 测试跨年的周

## 已知限制

1. 详情浮窗底部只有"添加任务"按钮，没有"添加日志"按钮
2. 目前不支持下拉刷新，需要切换视图或周份来刷新数据
3. 数据没有缓存机制，每次切换都会重新加载
