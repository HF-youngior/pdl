## 🚀 新增功能页面

### 1. 公司十大重要事项展示 (`CompanyImportantScreen`)
- **功能**：展示公司的重要事项
- **权限**：所有用户可查看，管理员和创始人可编辑
- **特性**：
  - 优先级显示（P0-P3）
  - 状态管理（待处理、进行中、已完成、已取消）
  - 截止时间显示
  - 刷新功能

### 2. 公司十大任务派发 (`CompanyTasksScreen`)
- **功能**：任务派发和管理
- **权限控制**：
  - 创始人：可创建任务，派发给部门总监
  - 部门总监：可查看上级任务，创建子任务派发给团队长
  - 团队长：可查看上级任务，创建子任务派发给员工
  - 员工：只能查看分配给自己的任务
- **特性**：
  - 任务层级管理
  - 优先级设置（P0-P3）
  - 状态筛选
  - 任务完成功能

### 3. 个人十大信息展示 (`PersonalImportantScreen`)
- **功能**：展示个人重要信息
- **数据来源**：根据日志信息自动生成
- **特性**：
  - 四象限分类（重要且紧急、重要不紧急、紧急不重要、不重要不紧急）
  - 关联任务显示
  - 手动编辑功能

### 4. 个人日志展示 (`PersonalLogsScreen`)
- **功能**：个人日志管理
- **特性**：
  - 分类筛选（工作、学习、个人、会议）
  - 四象限设置
  - 关联任务功能
  - 添加日志功能

## 📊 任务层级管理流程

### 创始人 → 部门总监
```
创始人创建任务 → 派发给部门总监 → 部门总监接收任务
```

### 部门总监 → 团队长
```
部门总监创建子任务 → 派发给团队长 → 团队长接收任务
```

### 团队长 → 员工
```
团队长创建子任务 → 派发给员工 → 员工接收任务
```

### 员工 → 上级汇报
```
员工完成任务 → 更新任务状态 → 上级收到通知 → 逐级汇报
```
