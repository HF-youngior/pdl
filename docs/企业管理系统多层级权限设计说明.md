# 企业管理系统多层级权限设计说明

## 系统概述

本系统实现了完整的企业多层级权限管理，支持五个用户级别：管理员、创始人、部门老总、团队长、员工，以及三个部门：人事部门、财务部门、宣传部。

- **数量**: 1个
- **权限**: 
  - 管理Web页面
  - 创建和管理所有用户账号
  - 编辑和选定公司10大重要事项
  - 查看所有数据和统计信息
- **测试账户**: admin / admin123

  - 财务组长: finance_team1 / financeteam123, finance_team2 / financeteam123

- **测试账户**:

## 核心功能

### 1. 公司十大重要事项管理
- **编辑权限**: 管理员、创始人
- **查看权限**: 所有用户
- **功能**: 
  - 创建和编辑重要事项
  - 从所有事项中勾选10条作为展示
  - 设置优先级（P0-P3）
  - 跟踪完成状态

### 2. 任务派发系统
- **创始人**: 派发任务给部门老总
- **部门老总**: 接收创始人任务，创建子任务派发给团队长
- **团队长**: 接收部门老总任务，创建子任务派发给员工
- **员工**: 接收团队长任务，完成任务并更新进度

### 3. 任务层级关系
- 支持主任务-子任务的多层级结构
- 任务完成会自动通知上级
- 支持任务进度百分比跟踪
- 支持特殊情况说明

### 4. 个人日志系统
- **四象限重要紧急程度**:
  - 重要且紧急 (important_urgent)
  - 重要不紧急 (important_not_urgent)
  - 不重要但紧急 (not_important_urgent)
  - 不重要不紧急 (not_important_not_urgent)
- 可关联具体任务
- 支持日志完成状态跟踪

### 5. 通知系统
- 任务分配通知
- 任务进度更新通知
- 任务完成通知
- 特殊情况通知

## 数据库设计

### 主要表结构
1. **departments** - 部门表
2. **users** - 用户表（支持层级关系）
3. **company_important_items** - 公司重要事项表
4. **tasks** - 任务表（支持层级关系）
5. **task_notifications** - 任务通知表
6. **personal_logs** - 个人日志表
7. **system_logs** - 系统日志表

### 关键字段说明
- **priority**: P0（最高优先级）到P3（最低优先级）
- **quadrant**: 四象限重要紧急程度分类
- **parent_id**: 用户层级关系
- **parent_task_id**: 任务层级关系
- **is_selected**: 是否被选为十大重要事项

## API接口说明

### 认证相关
- `POST /api/auth/login` - 用户登录
- `GET /api/user/profile` - 获取用户信息

### 用户管理
- `GET /api/users` - 获取用户列表（根据权限过滤）
- `GET /api/departments` - 获取部门列表

### 重要事项管理
- `GET /api/company-important-items` - 获取十大重要事项
- `GET /api/company-important-items/all` - 获取所有重要事项（管理员/创始人）
- `POST /api/company-important-items` - 创建重要事项
- `PUT /api/company-important-items/:id/select` - 选择/取消选择重要事项

### 任务管理
- `GET /api/tasks` - 获取任务列表（根据权限过滤）
- `POST /api/tasks` - 创建任务
- `PUT /api/tasks/:id/status` - 更新任务状态

### 通知系统
- `GET /api/notifications` - 获取通知列表
- `PUT /api/notifications/:id/read` - 标记通知为已读

### 个人日志
- `GET /api/personal-logs` - 获取个人日志
- `POST /api/personal-logs` - 创建个人日志
- `PUT /api/personal-logs/:id/complete` - 更新日志完成状态

## 权限控制

系统实现了严格的权限控制：
1. **数据可见性**: 根据用户角色限制可见的数据范围
2. **操作权限**: 不同角色有不同的操作权限
3. **层级管理**: 上级可以管理下级，下级只能看到分配给自己的任务
4. **任务派发**: 只能向直接下级派发任务

## 特色功能

1. **多层级任务派发**: 支持从创始人到员工的完整任务派发链条
2. **实时通知系统**: 任务状态变更会实时通知相关人员
3. **四象限日志管理**: 支持重要紧急程度的日志分类
4. **灵活的任务关联**: 个人日志可以关联具体任务
5. **进度跟踪**: 支持任务完成百分比的精确跟踪
6. **特殊情况处理**: 支持任务未完成时的特殊情况说明
