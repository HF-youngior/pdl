## 📊 核心逻辑

### 月视图：遍历日期范围

```javascript
// 对于跨多天的任务
const startDate = new Date(task.start_time);
const endDate = new Date(task.end_time);

// 遍历从开始到结束的每一天
while (currentDate <= endDate) {
  calendar[dateKey].tasks.push(task);
  currentDate.setDate(currentDate.getDate() + 1);
}
```

### 日视图：改进SQL查询

```sql
WHERE (
  DATE(start_time) = '2025-10-03'           -- 开始于该日
  OR DATE(end_time) = '2025-10-03'          -- 结束于该日
  OR (DATE(start_time) <= '2025-10-03'      -- 跨越该日
      AND DATE(end_time) >= '2025-10-03')
)
```

## 🐛 问题排查

### 如果修复后仍然只显示在开始日期

1. **确认服务器已重启**
   ```bash
   # 检查node进程是否是新启动的
   ps aux | grep node  # Linux/Mac
   tasklist | findstr node  # Windows
   ```

2. **清除浏览器缓存**
   - 按 `Ctrl + Shift + R` 强制刷新
   - 或在开发者工具中勾选"Disable cache"

3. **运行测试脚本确认**
   ```bash
   cd backend
   node verify_multiday_logic.js
   ```

4. **检查任务数据**
   确认任务有 `end_time` 字段：
   ```sql
   SELECT id, title, start_time, end_time 
   FROM tasks 
   WHERE id = 'task-hr-oct-001';
   ```
