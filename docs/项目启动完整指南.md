## 🔧 故障排除

### 常见问题

1. **数据库连接失败**
   - 检查MySQL服务是否启动
   - 确认密码是否正确：`asdfgh0625YYH`
   - 检查端口3306是否被占用

2. **后端服务启动失败**
   - 检查Node.js是否安装
   - 运行 `npm install` 安装依赖
   - 检查端口3000是否被占用

3. **Flutter应用无法连接后端**
   - 确认后端服务已启动
   - 检查API地址配置
   - 确认网络连接正常

### 验证步骤

1. **验证数据库**
   ```sql
   USE enterprise_management;
   SELECT username, password FROM users WHERE username = 'admin';
   -- 应该显示: admin | admin123
   ```

2. **验证后端服务**
   ```bash
   curl http://localhost:3000/api/departments
   -- 应该返回部门列表JSON
   ```

3. **验证登录功能**
   ```bash
   curl -X POST http://localhost:3000/api/auth/login \
   -H "Content-Type: application/json" \
   -d '{"username":"admin","password":"admin123"}'
   -- 应该返回用户信息和token
   ```
