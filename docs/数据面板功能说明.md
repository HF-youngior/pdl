# 个人资料页面数据面板功能实现

## 功能概述

在个人资料页面（ProfileScreen）中添加了一个数据面板，包含以下功能：

1. **今日数据统计**
   - 完成计划数统计（已完成/总数）
   - 完成率百分比显示

2. **近7日数据统计**
   - 可以通过切换按钮查看今日或近7日的数据
   - 包含相同的统计指标

3. **圆环形优先级分布图表**
   - 使用四象限分类法显示完成任务的优先级分布
   - 四个分类：
     - 重要且紧急（红色）
     - 重要不紧急（蓝色）
     - 紧急不重要（黄色）
     - 不重要不紧急（绿色）

4. **图例说明**
   - 显示每个优先级分类的具体数量
   - 使用颜色标识便于理解

## 技术实现

### 新增文件

1. **lib/services/statistics_service.dart**
   - 统计服务类，负责计算任务统计数据
   - 包含今日统计和近7日统计方法
   - 实现四象限优先级分类逻辑

2. **lib/widgets/data_panel.dart**
   - 数据面板组件
   - 使用fl_chart库绘制圆环图
   - 包含统计卡片和图例

### 修改文件

1. **pubspec.yaml**
   - 添加了fl_chart依赖用于图表绘制

2. **lib/screens/profile_screen.dart**
   - 集成了DataPanel组件
   - 在用户信息卡片下方显示数据面板

## 界面设计

数据面板采用卡片式设计，包含：

- **标题栏**：显示"今日数据"或"近7日数据"，右侧有切换按钮
- **统计卡片**：两个并排的卡片显示完成计划数和完成率
- **圆环图**：中央显示优先级分布的圆环图
- **图例**：底部显示各优先级分类的详细数量

## 数据来源

- 优先从TaskService获取真实的任务数据
- 当API调用失败时，提供模拟数据用于演示
- 支持按用户ID筛选任务数据

## 使用说明

1. 用户登录后，进入个人资料页面
2. 在用户信息卡片下方可以看到数据面板
3. 可以切换查看"今日"或"近7日"的数据
4. 圆环图直观显示任务优先级分布情况
5. 图例提供详细的数值信息

## 注意事项

- 需要确保后端API正常运行才能获取真实数据
- 图表颜色和样式可以根据需要调整
- 统计逻辑可以根据业务需求进一步优化
