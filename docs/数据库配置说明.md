# 数据库配置说明

## 1. 创建 .env 文件

在 `backend` 文件夹中创建一个名为 `.env` 的文件，内容如下：

```
# 数据库配置
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=您的MySQL密码
DB_NAME=enterprise_management
DB_PORT=3306

# JWT密钥
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production

# 服务器端口
PORT=3000
```

## 2. 修改配置

请将 `DB_PASSWORD=您的MySQL密码` 中的 `您的MySQL密码` 替换为您实际的MySQL root密码。

例如，如果您的MySQL密码是 `123456`，则应该写为：
```
DB_PASSWORD=123456
```

## 3. 其他配置项说明

- `DB_HOST`: 数据库主机地址，本地开发通常是 `localhost`
- `DB_USER`: 数据库用户名，通常是 `root`
- `DB_NAME`: 数据库名称，我们使用 `enterprise_management`
- `DB_PORT`: 数据库端口，MySQL默认是 `3306`
- `JWT_SECRET`: JWT令牌密钥，生产环境请使用更复杂的密钥
- `PORT`: 后端API服务器端口，默认是 `3000`

## 4. 数据库初始化

配置完成后，请运行以下命令初始化数据库：

```sql
-- 1. 登录MySQL
mysql -u root -p

-- 2. 创建数据库
CREATE DATABASE enterprise_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 3. 导入数据库结构
USE enterprise_management;
SOURCE backend/database.sql;
```

或者直接使用命令行：
```bash
mysql -u root -p enterprise_management < backend/database.sql
```

## 5. 启动服务器

配置完成后，运行：
```bash
cd backend
npm install
npm start
```

服务器启动后，您应该看到：
```
数据库连接成功
服务器运行在端口 3000
API地址: http://localhost:3000/api
```
