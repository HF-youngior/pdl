## ✅ 已完成的修复

## 🔧 配置步骤

### 步骤 1：确保后端服务器正在运行

后端服务器必须绑定到 `0.0.0.0` 才能被手机访问。如果服务器正在运行，请重启它：

```bash
cd backend
node server_enterprise.js
```

### 步骤 2：配置手机应用

应用安装到手机后，按以下步骤配置：

1. **打开应用**
2. **进入设置页面**（点击底部导航栏的"设置"）
3. **找到"服务器地址"选项**，点击进入
4. **输入服务器配置**：
   - **服务器IP地址**：`10.61.194.8`（你的电脑IP）
   - **端口**：`8080`
5. **点击"保存"**
6. **重启应用**（完全关闭后重新打开）

### 步骤 3：检查防火墙设置

确保 Windows 防火墙允许 8080 端口的连接：

1. 打开"Windows Defender 防火墙"
2. 点击"高级设置"
3. 选择"入站规则" → "新建规则"
4. 选择"端口" → 下一步
5. 选择"TCP"，输入端口 `8080`
6. 选择"允许连接"
7. 应用到所有配置文件
8. 命名规则（如"Flutter 后端服务器"）

或者使用 PowerShell 快速添加规则：

```powershell
New-NetFirewallRule -DisplayName "Flutter Backend Server" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow
```

### 步骤 4：测试连接

配置完成后，尝试登录应用。如果能够成功登录，说明配置正确。

## 🔍 故障排除

### 问题 1：手机无法连接到服务器

**可能原因：**
- 防火墙阻止了连接
- 服务器未绑定到 0.0.0.0
- IP 地址配置错误
- 手机和电脑不在同一 WiFi 网络

**解决方法：**
1. 检查防火墙设置（见步骤 3）
2. 确认服务器正在运行并绑定到 0.0.0.0
3. 确认手机和电脑连接的是同一个 WiFi（phone.wlan.bjtu）
4. 在手机上用浏览器访问 `http://10.61.194.8:8080/api` 测试连接

### 问题 2：配置保存后仍无法连接

**解决方法：**
1. 完全关闭应用（从后台任务中清除）
2. 重新打开应用
3. 检查设置中的服务器地址是否正确显示

### 问题 3：校园网限制

如果校园网有防火墙或网络隔离：
- 尝试使用手机热点（手机开热点，电脑连接）
- 或联系网络管理员开放 8080 端口
