## 技术栈
- **前端**: Flutter 3.9.2 + Material Design
- **后端**: Node.js + Express + JWT认证
- **数据库**: MySQL 8.0
- **Web管理端**: HTML5 + Bootstrap 5 + JavaScript
- **API通信**: HTTP RESTful API

## 启动说明

### 1. 数据库设置
```sql
CREATE DATABASE enterprise_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
mysql -u root -p enterprise_management < backend/database.sql
```

### 2. 启动后端服务器
```bash
cd backend
npm install
npm start
```

### 3. 启动Flutter应用
```bash
flutter pub get
flutter run
```

### 4. 启动Web管理端
直接打开 `web_admin/index.html` 文件
