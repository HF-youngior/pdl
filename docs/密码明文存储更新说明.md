# 数据库密码明文存储更新说明

## 更新概述

根据要求，已将企业管理系统数据库中的所有用户密码从加密存储改为明文存储，以便于测试和开发使用。

## 修改的文件

### 1. 数据库初始化文件
- `database.sql` - 基础数据库初始化脚本
- `enterprise_management_clean.sql` - 完整的多层级权限数据库脚本

### 2. 数据库更新脚本
- `update_passwords_to_plaintext.sql` - 将现有加密密码更新为明文密码的SQL脚本
- `update_passwords_to_plaintext.bat` - 执行密码更新的批处理脚本

## 使用方法

### 方法1: 重新初始化数据库
1. 删除现有数据库
2. 运行 `enterprise_management_clean.sql` 脚本
3. 所有用户密码将直接以明文形式创建

### 方法2: 更新现有数据库
1. 运行 `update_passwords_to_plaintext.bat` 批处理脚本
2. 输入MySQL root密码
3. 脚本将自动更新所有现有用户的密码

## 技术说明

### 密码验证逻辑
服务器端代码 (`server_enterprise.js`) 中的密码验证逻辑已经支持明文密码比较：

```javascript
// 直接比较明文密码
const isValidPassword = (password === user.password);
```

### 安全注意事项
⚠️ **重要提醒**: 明文密码存储仅适用于开发和测试环境，生产环境应使用加密存储。
