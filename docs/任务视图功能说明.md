# 任务视图功能说明

## 功能概述

任务视图功能提供了完整的日历和任务管理系统，支持三种视图模式：月视图、周视图和日视图。

## 主要功能

### 1. 视图切换
- **月视图**：以甘特图形式显示整月的任务安排
- **周视图**：显示一周内的任务分布
- **日视图**：精确显示某一天每个时段的具体任务

### 2. 任务管理
- **创建任务**：点击右上角"+"按钮或长按日期创建新任务
- **编辑任务**：点击任务块查看详情，可进行编辑
- **删除任务**：在任务详情对话框中删除任务
- **任务属性**：
  - 标题和描述
  - 开始时间和结束时间
  - 全天任务标记
  - 地点信息
  - 优先级（低/中/高）
  - 自定义颜色

### 3. 颜色自定义
支持8种预设颜色：
- 绿色 (#4CAF50)
- 蓝色 (#2196F3)
- 红色 (#F44336)
- 橙色 (#FF9800)
- 紫色 (#9C27B0)
- 粉色 (#E91E63)
- 青色 (#00BCD4)
- 黄色 (#FFEB3B)

## 使用方法

### 访客登录
1. 在登录界面点击"访客登录"按钮
2. 无需输入用户名和密码即可进入系统

### 查看任务
1. 进入"视图"页面
2. 默认显示月视图
3. 使用右上角的视图切换按钮切换视图模式
4. 使用左右箭头导航到不同时间段

### 创建任务
1. 点击右上角"+"按钮创建新任务
2. 或长按日历中的任意日期快速创建
3. 填写任务信息：
   - 任务标题（必填）
   - 任务描述（可选）
   - 开始和结束时间
   - 地点（可选）
   - 优先级
   - 颜色
4. 点击"保存"完成创建

### 编辑任务
1. 点击任务块查看详情
2. 在详情对话框中点击"编辑"
3. 修改任务信息
4. 点击"保存"完成修改

### 生成测试数据
1. 点击右上角的数据图标
2. 确认生成示例任务
3. 系统会自动创建10个示例任务用于测试

## 技术特性

### 前端功能
- 响应式设计，适配不同屏幕尺寸
- 流畅的动画和交互效果
- 支持下拉刷新
- 错误处理和用户反馈

### 后端支持
- RESTful API设计
- 数据库字段扩展
- 时间范围查询
- 完整的CRUD操作

### 数据库结构
任务表新增字段：
- `start_time`: 任务开始时间
- `end_time`: 任务结束时间
- `color`: 任务颜色
- `location`: 任务地点
- `is_all_day`: 是否全天任务

## 更新说明

### 数据库迁移
如果已有数据库，需要运行迁移脚本：
```bash
# Windows
cd backend
更新任务表.bat

# 或手动执行SQL
mysql -u root -p enterprise_management < migrate_tasks.sql
```

### 后端更新
后端API已更新支持新的任务字段和功能：
- GET /api/tasks - 支持时间范围查询
- POST /api/tasks - 创建任务
- PUT /api/tasks/:id - 更新任务
- DELETE /api/tasks/:id - 删除任务

## 注意事项

1. 确保后端服务正在运行
2. 数据库连接正常
3. 网络连接稳定
4. 建议先使用访客登录进行测试

## 故障排除

### 任务不显示
- 检查后端服务是否运行
- 确认数据库连接正常
- 尝试刷新页面

### 创建任务失败
- 检查网络连接
- 确认后端API正常
- 查看错误提示信息

### 数据库错误
- 运行数据库迁移脚本
- 检查数据库权限
- 确认表结构正确
