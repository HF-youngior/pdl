# 周视图任务矩形框优化说明

## 优化时间
2025年10月30日

## 优化内容

### 1. 增加任务矩形框高度
- **行高度**: 从 `50` 增加到 `70` 像素
- **矩形框高度**: 从 `34` 增加到 `50` 像素
- **垂直位置**: 从 `top: 8` 调整到 `top: 10`

### 2. 移除图标显示
- **移除内容**: 删除任务/日志的图标显示
- **只显示标题**: 标题居中显示，更简洁清晰
- **布局优化**: 使用 `Center` 和 `textAlign: TextAlign.center` 居中对齐

### 3. 增大文字显示
- **字体大小**: 从 `11` 增加到 `13`
- **文字对齐**: 居中显示（`textAlign: TextAlign.center`）
- **水平内边距**: 从 `8` 减少到 `6`
- **垂直内边距**: 从 `8` 减少到 `4`

### 4. 优化边框和圆角
- **边框宽度**: 从 `1.5` 增加到 `2`
- **圆角半径**: 从 `6` 增加到 `8`

### 5. 支持多行标题
- **最大行数**: 从 `1` 增加到 `2`
- **溢出处理**: 保持 `TextOverflow.ellipsis`（使用省略号）

## 优化效果

### 视觉效果
1. **更简洁的设计**: 移除图标后，界面更加简洁清爽
2. **更清晰的标题显示**: 增大的字体让标题更容易阅读，居中显示更美观
3. **更好的空间利用**: 50像素的高度可以容纳更长的标题
4. **支持两行标题**: 如果标题太长，可以自动换行到第二行
5. **更突出的矩形框**: 更粗的边框让任务条更显眼

### 用户体验提升
1. **界面更简洁**: 移除不必要的图标，聚焦于标题内容
2. **标题可读性**: 标题居中显示，太长时用省略号（...）处理
3. **视觉层次**: 更大的矩形框让任务在甘特图中更醒目
4. **信息密度**: 在保持清晰的同时，显示更多标题信息
