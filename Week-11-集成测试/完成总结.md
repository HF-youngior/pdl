## 🚀 使用方法

### 快速开始

1. **查看报告**: 双击 `查看报告.bat`
2. **生成统计**: 双击 `生成测试统计.bat`
3. **运行 Newman**: 双击 `运行Newman测试.bat`

### 手动操作

1. **查看主报告**: 直接打开 `index.html`
2. **导入 Postman**: 导入 `enterprise-api-collection.json`
3. **生成 Newman 报告**: 
   ```bash
   cd backend
   npx newman run enterprise-api-collection.json -r htmlextra --reporter-htmlextra-export newman-full-report.html
   ```
