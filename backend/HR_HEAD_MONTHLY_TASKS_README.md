如需清除这些任务数据：
```sql

WHERE assignee_id = 'dept-head-001' 
AND (id LIKE 'task-hr-sep-%' 
  OR id LIKE 'task-hr-oct-%' 
  OR id LIKE 'task-hr-nov-%' 
  OR id LIKE 'task-hr-dec-%');
```
