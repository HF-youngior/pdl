POST /api/mbti-records 创建MBTI性格测试记录，记录用户的MBTI类型和测试结果
🔒 此接口需要认证
请求参数
接口名称：创建MBTI记录；请求参数类型：JSON（application/json）
参数名 类型 必填 说明
mbti_type string 必填 MBTI类型，如：ENFP
test_scores object 必填 测试分数，包含E/I/S/N/T/F/J/P等维度
personality_traits object 必填 性格特质描述
personal_info object 可选 个人信息
test_version string 可选 测试版本，默认v1.0
接口测试

AI分析

POST /api/ai/analyze-log 分析日志文本内容，提取关键词和主题，用于生成词云
请求参数
接口名称：分析日志文本；请求参数类型：JSON（application/json）
参数名 类型 必填 说明
text string 必填 要分析的文本内容
topK number 可选 返回前K个关键词，默认20
接口测试
GET /api/ai/analyze-today 一键分析今日所有日志，使用DeepSeek AI进行智能分析，生成总结和洞察
🔒 此接口需要认证。使用DeepSeek API进行智能分析。
接口测试
POST /api/ai/save-wordcloud 保存词云分析结果，包括关键词和词频数据
🔒 此接口需要认证
请求参数
接口名称：保存词云分析结果；请求参数类型：JSON（application/json）
参数名 类型 必填 说明
analysisDate string 可选 分析日期
keywords array 必填 关键词数组
wordFrequencies array 必填 词频数组
description string 可选 描述
接口测试

🔒 此接口需要认证
接口测试
