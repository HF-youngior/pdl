v1.0.0 | 接口测试与文档

先调用登录接口获取 Token，然后粘贴到这里。后续所有需要认证的接口会自动携带此 Token。

用户认证

POST /api/auth/login 用户登录
请求参数
参数名 类型 必填 说明
username string 必填 用户名
password string 必填 密码
请求示例
{ "username": "admin", "password": "admin123" }
响应示例
{ "message": "登录成功", "user": { "id": "admin-001", "username": "admin", "name": "System Admin", "role": "admin" }, "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." }

公司重要事项

GET /api/company-important-items 获取重要事项（分页）
查询参数
参数名 类型 必填 说明
page number 可选 页码，默认 1
pageSize number 可选 每页数量，默认 10
请求示例
GET /api/company-important-items?page=1&pageSize=10
响应示例
{ "data": [ { "id": 1, "title": "重要事项标题", "description": "事项描述", "is_selected": true, "created_at": "2025-10-16T10:00:00.000Z" } ], "total": 50, "page": 1, "pageSize": 10 }
接口测试
GET /api/company-important-items/all 获取所有重要事项（不分页）
接口测试
POST /api/company-important-items 创建重要事项
请求参数
参数名 类型 必填 说明
item_id number 必填 重要事项库 ID
请求示例
{"item_id": 1}
响应示例
{ "message": "重要事项添加成功", "id": 1 }

月视图日历

GET /api/calendar/month-view 获取指定月份的任务和日志
🔒 此接口需要认证。用于月视图日历显示，返回整个月每天的任务和日志数据。
查询参数
参数名 类型 必填 说明
year number 必填 年份，例如: 2025
month number 必填 月份，1-12
请求示例
GET /api/calendar/month-view?year=2025&month=10
响应示例
{ "year": 2025, "month": 10, "days": [ { "date": "2025-10-01", "tasks": [ { "id": "task-001", "title": "完成季度报告", "status": "in_progress", "priority": "p0", "color": "#FF5722" } ], "logs": [ { "id": "log-001", "title": "日志标题", "content": "日志内容" } ], "hasData": true } ], "summary": { "totalTasks": 15, "totalLogs": 8, "daysWithData": 12 } }
接口测试
