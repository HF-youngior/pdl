📝 请求参数
参数名 类型 必填 说明

{ "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "user": { "id": 1, "username": "admin", "realname": "系统管理员", "role": "admin" } }

📋 公司重要事项

GET /api/company-important-items 获取公司重要事项 (分页) ▼
📝 查询参数
参数名 类型 必填 说明
page number 可选 页码 (默认: 1)
pageSize number 可选 每页数量 (默认: 10)
🧪 API 测试
GET /api/company-important-items/all 获取所有公司重要事项 (不分页) ▼
🧪 API 测试
POST /api/company-important-items 创建公司重要事项 ▼
📝 请求参数
参数名 类型 必填 说明
item_id number 必填 重要事项库 ID
📤 请求示例
{"item_id": 1}
🧪 API 测试
PUT /api/company-important-items/:id/select 选择/取消选择事项 ▼
📝 请求参数
参数名 类型 必填 说明
:id number 必填 URL 路径参数 - 事项 ID
is_selected boolean 必填 是否选择 (true/false)
📤 请求示例
PUT /api/company-important-items/1/select {"is_selected": true}
