# 🚀 快速开始

## 一键加载所有数据

### Windows用户

双击运行以下文件即可：

```
load_all_data.bat
```

然后选择：
- **选项 8** - 全部加载（推荐新环境使用）

这会自动完成：
✅ 初始化数据库  
✅ 加载所有基础数据  
✅ 为 hr_head 用户添加约150条日志（2025年9-11月）  

## 数据说明

- **总数**: 149条日志
- **时间**: 2025年9-11月
- **覆盖**: 约2/3的天数
